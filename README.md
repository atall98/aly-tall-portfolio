# Portfolio Aly Tall

Portfolio responsive réalisé en HTML, CSS et JavaScript.

## Fonctionnalités
- Interface desktop et mobile
- Menu hamburger sur mobile
- Navigation fluide avec sections
- Animation d'apparition au scroll
- Cartes de compétences
- Présentation des projets avec fenêtre modale
- Section expériences
- Formulaire de contact avec validation côté navigateur
- Bouton retour en haut
- Design sombre / vert avec une présentation moderne

## Structure
portfolio_aly_tall/
├── index.html
├── style.css
├── script.js
└── README.md

## Lancer le projet
1. Téléchargez ou décompressez le dossier.
2. Ouvrez `index.html` dans Chrome, Edge ou Firefox.
3. Pour travailler avec VS Code, vous pouvez utiliser l'extension Live Server.

## Personnalisation
- Les informations principales sont dans `index.html`.
- Les couleurs et le responsive sont dans `style.css`.
- Les interactions sont dans `script.js`.
- Remplacez les textes des expériences et projets par les informations exactes si nécessaire.
